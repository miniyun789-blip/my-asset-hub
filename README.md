# My Asset Hub · v0.9.0 사용자 테스트

Build: `20261106-prod-01` · Worker: `my-asset-hub`

## 사용 방법

1. 기존 자산은 그대로 두고 리밸런싱 → 전체 리밸런싱에서 리스크 목표 합계만 100%로 설정합니다.
2. 월 투자에서 **이미 등록된 현금 중 이번에 쓸 예산**을 입력합니다. 별도 신규 입금으로 더하지 않습니다.
3. 부족 그룹에 배분하고, 그룹 안에서는 원화 평가수익률이 낮은 보유 종목부터 제안합니다. 이는 사용자가 정한 추천 순서이며 투자 적합성 평가가 아닙니다.
4. 추천행에서 다른 보유 종목을 선택하거나 그룹을 건너뛸 수 있습니다. 건너뛴 그룹의 예산은 다른 그룹에 억지로 재배분하지 않습니다.
5. 실제 매수한 수량·가격·수수료만 체결 입력합니다. 앱은 금융기관에 주문하지 않습니다.
6. 전체 리밸런싱에서는 초과 그룹의 수익률 높은 종목부터 매도 제안하고, 필요한 거래행에서 수량 유지를 선택합니다.

## 계산과 현금 정책

- 모든 주식·코인·은행 현재잔액·현금을 총자산과 리스크 비중에 포함합니다.
- 종목별 목표비중은 입력하지 않습니다. 기존 allocations 데이터는 백업 호환성을 위해 보존하지만 새 추천에서는 사용하지 않습니다.
- 고정 은행자산은 금액 유지. 주식/ETF는 정수, 코인은 최대 8자리 수량. 맞출 수 없는 잔액은 현금으로 유지합니다.
- 실제 매수 재원은 현금 우선, 이후 유동 은행자산 displayOrder 및 ID 순입니다. 전체 유동 잔액의 최소 현금을 보존합니다.
- 추천은 거래 후 실제 재원 이동까지 반영해 그룹 비중 오차가 줄어드는 경우에만 매수합니다. 현금을 같은 그룹의 채권으로 옮기는 것만으로 그 그룹 비중이 높아졌다고 계산하지 않습니다.
- 안전 그룹 내 매매 가능한 종목은 다른 부족 그룹을 채울 현금이 모자랄 때 매도할 수 있습니다. 고정 은행자산은 매도하지 않습니다.
- 월급은 외부유입으로 총자산 증가, 적금/청약은 내부이동으로 총자산 유지.

## 데이터 보존과 되돌리기

schema 4 / 저장 키 `my-asset-hub-beta-v4` 유지. v0.7 및 기존 Excel/JSON migration 유지.
첫 v0.9 변환 전 원본은 같은 키의 `-before-v09`에 복사합니다. 금액·수량을 초기화하지 않습니다.
`config.safeRiskId`는 기본 risk_4 또는 기존 사용자 정의 현금 그룹 ID를 안정적으로 유지하며 이름 변경과 분리합니다.
`config.allocationPolicy='risk-return'` 추가. 자동반영 undo는 잔액과 이력을 복구하되 해당 월 처리 기록을 남겨 다음 실행에서 다시 반영하지 않습니다.
직전 실행 undo는 전체 사본 복구이므로 이후 직접 편집 내용도 되돌립니다.

## 검증

```sh
npm ci
npm run check
npm test
npm run test:browser
```

이번 환경에서는 check/86개 자동 테스트 및 Chromium 수동 주요 흐름을 확인했습니다. `test:browser` 자동 suite는 실행하지 않았습니다. 실제 Android/iPhone 설치와 외부 API 최신 동작도 별도 확인이 필요합니다. 자세한 내용은 TEST_REPORT.md.

## 업데이트·배포

- GitHub에는 코드만 업로드합니다. 개인 JSON/Excel은 올리지 않습니다.
- Cloudflare Worker `my-asset-hub`의 Git 연결이 main을 추적한다면 main 업데이트 후 자동 빌드를 확인합니다.
- 직접 배포는 본인 환경에서 Cloudflare 로그인 후 `npm ci`, `npx wrangler deploy`를 실행합니다.
- 배포 후 `/api/health`의 version `0.9.0`, build `20261106-prod-01`과 화면 하단을 대조합니다.
- 홈 화면 PWA는 온라인에서 다시 열어 업데이트합니다. 업데이트 확인을 위해 브라우저 데이터를 지우지 마세요.
- Android: Chrome 메뉴 → 앱 설치/홈 화면 추가. iPhone: Safari 공유 → 홈 화면에 추가.
- 롤백 코드: `backup/pre-v0.9.0-20261106`. 배포 전 JSON 백업 권장.

이 세션에서는 Cloudflare 배포 자격 증명이 없어 실제 Worker 배포를 수행하지 않았습니다.
